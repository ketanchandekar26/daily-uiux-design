Day 006 UX Specifications

1. Cognitive Psychology

  • Heuristic #3 (User Control & Freedom): The floating unsaved changes bar alerts users of pending state modifications and allows 1-click discarding without accidental data loss.
  • Goal-Gradient Effect: The 92% profile completion meter motivates users to complete remaining profile information by showing immediate near-completion status.
  • Miller's Law (Information Architecture): Settings are organized into 4 logical categorical tabs (General, Security, Notifications, Danger) to prevent deep scroll fatigue.

2. Accessibility (WCAG 2.1 AA)

Custom switch toggles use `role="switch"` and update `aria-checked="true|false"` dynamically.
Contrast ratios for all typography exceed 4.8:1 against deep slate backdrops.
Accessible tab navigation with `role="tablist"`, `role="tab"`, and keyboard arrow navigation.

3. Frontend UX Engineering

• Stateful Dirty-Checking: Listens to all inputs to automatically show or hide the floating save notification.

• Interactive Tag Architecture: Add and remove technology chips with immediate DOM re-render.
