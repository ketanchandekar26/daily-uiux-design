Day 007 UX Specifications

1. Cognitive Psychology

  • Principle of Least Privilege (Security UX): Users are guided toward conservative permissions by default. Destructive or wide privileges (Admin/Owner) carry contextual warning callouts.
  • Miller's Law (Chunking Complexity): Dense IAM configuration is separated into 4 isolated domains (Roles, API Keys, SSO, Audit Trail) to prevent mental overload.
  • Heuristic #5 (Error Prevention): One-time token generation visibility prevents insecure key storage while offering 1-click clipboard capture.

2. Accessibility (WCAG 2.1 AA)

WAI-ARIA Dialog Pattern: `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, and `aria-describedby`.
Focus Trapping: Tabbing is securely restricted within the modal container while open.
Focus Restoration: Closing the dialog immediately restores focus to the invoking trigger button.
Escape Key Listener: Instant dismissal via Esc.

3. Frontend UX Engineering

• Stateful Event Bus: Role mutations, member deletions, and token generations immediately append to the live Audit Trail.

• Zero-Dependency Architecture: 100% standalone single-file code with Tailwind CDN and Lucide Icons.
